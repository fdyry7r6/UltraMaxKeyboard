# Top Topy Board — Font Studio

Top Topy Board is a customized build based on the **HeliBoard open-source keyboard codebase**. The Top Topy additions are kept under `helium314.keyboard.toptopy` and related toolbar/IME integration points.

## Unicode Font Styles

The Font Studio converts typed/selected Latin text to Unicode-styled characters. It does not secretly log or upload typed text.

Included styles:

- Normal
- Bold
- Italic
- Bold Italic
- Sans
- Sans Bold
- Sans Italic
- Sans Bold Italic
- Script
- Bold Script
- Fraktur
- Bold Fraktur
- Double Struck
- Monospace
- Fullwidth
- Circled / Bubble
- Negative Circled
- Squared
- Small Caps
- Upside Down
- Wide Spacing
- Bracketed
- Aesthetic / Fullwidth

## Important

These are Unicode text styles. They are intentionally portable: the resulting characters can be pasted into Telegram, Instagram, WhatsApp, browsers, etc. The exact appearance depends on the destination app's font support.
